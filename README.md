# ANFP - Evaluación Final Transversal

( DISCULPE PROFESOR LE DEJO SUBIDO AQUI EL WORD CON LOS DIAGRAMAS NO LO SUBI AL AVA POR ERROR )

Proyecto de base de datos desarrollado para la Evaluación Final Transversal (EFT), basado en el caso de la Asociación Nacional de Fútbol Profesional (ANFP).

## Descripción

El proyecto implementa una base de datos relacional en Oracle Database 19c para gestionar información relacionada con clubes de fútbol, asociaciones, regiones, comunas, nacionalidades, jugadores y trabajadores.

## Tecnologías

- Oracle Database 19c
- Oracle SQL Developer
- SQL / DDL / DML

## Contenido

El script incluye:

- Creación de tablas.
- Claves primarias y foráneas.
- Restricciones `CHECK`, `UNIQUE` y `NOT NULL`.
- Secuencia para la generación de códigos de clubes.
- Columna `IDENTITY` para nacionalidades.
- Poblamiento de las tablas solicitadas.
- Consultas SQL para los informes requeridos.

## Informes

El proyecto incluye consultas para:

1. Obtener las asociaciones de fútbol profesional creadas después del año 2000.
2. Obtener el patrimonio de los clubes que cumplen los criterios solicitados y convertirlo a dólares.
